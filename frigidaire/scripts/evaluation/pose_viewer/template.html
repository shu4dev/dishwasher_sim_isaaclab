About this experiment and coordinate system

The experiment sampled 100 proposals for each of three objects on each rack, with uniform 3D rotations. Objects that passed the initial collision check were released and allowed to settle before the selected rack retracted. Acceptance required support, rest, whole-mesh containment within 1 mm, rack closure within 5 mm, and the recorded contact limits. Door closure, an insertion path from outside the rack, and multi-object capacity were not tested.

All coordinates are in world metres with Z up; stored quaternions use X, Y, Z, W order. “Sampled” shows the proposed world pose with the selected rack open; 395 colliding proposals were never physically released. These appear only when Sampled is explicitly selected, as red ghosts labeled “Never dropped.” “Settled” is the measured pre-retraction pose. “Final” is the last saved final-hold pose when available. Missing stages remain empty: the viewer never substitutes a proposal for a final result. The gray enclosure outline represents the nominal containment boundary.

Only the selected rack transform was saved at initialization, so the sampled view omits other component meshes. Strict containment is an additional zero-tolerance filter in both world and measured Cabinet frames. Accepted placements passed this simulation's checks; normal-use reachability and repeatability in a real dishwasher have not been established.
