# Lower rack polish from four reference views

The revision is generated by `frigidaire/src/dishsim_frigidaire/lower_rack_asset.py`. It applies only to
the standalone Bosch asset's lower rack; `rack_gen.py`, benchmark geometry, slot
configuration, cached collision worlds, middle rack, and third tray are outside
its scope.

Current status: **geometry built and checked; not installed or validated in Isaac
Sim.** The editing session cannot write through the external `assets/` symlink or
connect to the Docker socket, and has no NVIDIA device or local `pxr` package.
The existing `assets/models/bosch800/*.usdc` files have not been changed. Generated
files are staged in `build/bosch800_lower_rack/`, inside the writable checkout.

## Reference interpretation

The local images in `media/rack_images/bottom_rack/` guide these features:

| View | Geometry traced from that view |
|---|---|
| `front.webp` | Three rounded front rails, bare raised wire grip, tall rear wall, two rear tine banks |
| `left.webp` | Shallow V saddles in longitudinal floor wires, front tine lean, stepped side rail, four rollers per side |
| `top.webp` | Sparse floor topology, two transverse rear banks and four longitudinal front combs, open peripheral bays |
| `top_right.webp` | Wall-to-floor bends, wheel clips, rear bank release paddle, wire thickness and rounded tine ends |

The model uses seven long floor ribs, two rear banks of 17 tines, and four front
combs of seven tines. Rear tines lean toward negative X; front tines lean toward
the front (negative Y). The tall folding bank has darker coating, two small pivot
collars, and a single side release paddle. These mechanisms are fixed geometry.

All wire bends use circular fillets and swept round sections with smooth normals.
Tine ends are closed hemispherical caps. Main wires are approximately 4 mm in
diameter, rims 5 mm, and tines 3.7 mm. The eight 35 mm wheels have annular treads,
recessed spokes, hubs and attachment clips. Wire material is dark blue-gray coated
steel, with darker polymer hardware. The reference photographs show a bare rack,
so the old broad plastic grip and cutlery basket are absent from this revision.

The resulting bounds are approximately **519 × 553 × 194 mm**, including the
forward wire handle. Floor origin, metre units, Z up, and front at negative Y
follow the existing asset convention. All local dimensions and counts are photo
interpretations, not manufacturer CAD measurements.

## Build and inspect

From the repository root, using a Python with numpy:

```bash
python3 frigidaire/scripts/setup/polish_lower_rack.py --preview
```

This writes a portable `lower_rack.usda`, `geometry_validation.json`, and
`geometry_preview.png` into `build/bosch800_lower_rack/`. The preview is a
matplotlib geometry diagnostic, explicitly labeled **not an Isaac Sim render**.
The staged USDA has no texture dependencies.

The builder checks finite vertices/normals, nondegenerate triangles, consistent
outward winding, positive volume, closed manifold edges, rack bounds, eight wheel
positions, and the tine-bank layout. Physics uses individual capsules following
the wire centre-lines (maximum simplification error 0.2 mm), eight wheel cylinders,
and the existing friction values. There is no solid floor or basket-shaped collider.

## Install and capture in the project runtime

In an environment with access to `dishsim-isaac` and write access to the asset and
media directories:

```bash
scripts/run_py.sh frigidaire/scripts/setup/polish_lower_rack.py --install
scripts/run_kit.sh frigidaire/scripts/evaluation/lower_rack_polish_evidence.py --headless --enable_cameras
```

The installer stages both USDC files, checks USD mesh topology and material paths,
and compares the entire authored layer outside `LowerRack` for exact equality.
It preserves the existing lower-body transform, mass, inertia, other root
attributes, and physics APIs. The revised geometry includes new candidate
manipulation sites, which require renewed dish-contact validation. Before
replacement, original files are backed up under
`assets/models/bosch800/backups/lower_rack_polish/` with content hashes; a failed
replacement restores both originals. Texture paths remain relative.

The capture script can also inspect the staged USDA without installing:

```bash
scripts/run_kit.sh frigidaire/scripts/evaluation/lower_rack_polish_evidence.py --headless --enable_cameras \
  --usd build/bosch800_lower_rack/lower_rack.usda
```

It produces exactly one 1920 × 1440 PNG (`lower_rack.png`) and one 19-second,
30 fps H.264 video (`lower_rack.mp4`) in `media/bosch800_lower_rack_polish/`.
The video orbits the rack, then moves overhead to show the tine arrangement.
An accompanying `evidence.json` records the actual runtime version, source asset
hash, frame count, and measured wheel/floor settling. A capture passes only after
the rack settles stably on its wheels and both media files are written. Neither
the installer nor the capture script has been executed in Isaac during this edit.

This capture validates the loose rack's floor contacts and appearance. Dish loading,
retrieval, and the appliance's articulation cycle require separate revalidation;
the older asset's recorded PASS results do not validate the new rack.
