# execution/frigidaire

UR5e + Robotiq 2F-85 in the Frigidaire twin: the asset mirror, the bring-up probes, the robot episode and its
report (plan `plans/2026-09-29-easy-s0.md`), then the hardware-limits study of 2026-10-23 to 2026-10-30: the reach
sweep, the drop and tines tests, the Part B loads, the Warp replays and the two report pages (reference
`code/frigidaire/docs/robot.md`). Defaults are defined in the script itself unless another file is named. Kit =
through `code/util/run_kit.sh ... --headless`; Kit-free = `code/util/run_py.sh` or the Mac's python.
