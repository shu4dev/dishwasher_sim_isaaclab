# execution/frigidaire

UR5e + Robotiq 2F-85 in the Frigidaire twin: the asset mirror, the bring-up probes, the robot episode and its
report (plan `plans/2026-09-29-easy-s0.md`; reference `code/frigidaire/docs/robot.md`). Defaults are defined in
the script itself unless another file is named. Kit = through `code/util/run_kit.sh ... --headless`.

| Script | What it does | Key parameters (default) | Reads | Writes |
|---|---|---|---|---|
| `mirror_robot_usd.sh` | Host. Mirrors the Isaac 6.0 UR5e + 2F-85 and converts its two crate-0.9 layers to text usda in a throwaway usd-core venv; idempotent. | `USD_CORE_VERSION` (required, pinned by the caller), `TMPDIR` (`/media/corallab-s1/2tbhdd/brianshu/dishsim/tmp`) | the public asset bucket | `data/assets/robots/`, `CONVERSION.json` |
| `robot_asset_manifest.py` | Kit-free. One sha256 line per mirrored file, plus the converted layers and the usd-core version. | `--check` (verify the tree instead of writing) | `data/assets/robots/` | `data/assets/robots/MANIFEST.sha256` |
| `frigidaire_robot_smoke.py` | Kit. Spawn, reach HOME_Q, open and close the gripper, measure the finger travel. | none | the robot asset | `data/results/robot/smoke/smoke.json` (stills with cameras) |
| `frigidaire_grip_colliders.py` | Kit. Which robot prims carry colliders, which are disabled or filtered, the collision groups; read-only on the asset. | none | the robot asset | `data/results/robot/grip_probe/colliders.json` |
| `frigidaire_grip_probe.py` | Kit. Friction gate G0: a HOTEC bowl held by a rim pinch with no weld; PASS = < 5 mm slip over 3 s. | `--effort` (10 N m), `--stiffness` (40), `--insert-mm` (12), `--close` (0.8 rad), `--object` (`bowl`), `--inverted`, `--lying`, `--foot-clamp`, `--fix` (`none`), `--tag` (`base`) | the robot asset, the HOTEC v2 bowl | `data/results/robot/grip_probe/<tag>.json` |
| `frigidaire_grasp_test.py` | Kit. The generated grasps on one bowl per pose class: descend, close, lift 10 cm, hold 3 s; PASS = lifted >= 5 cm with < 5 mm drift. | `--pose` (`lying`; or `upright`, `inverted`), `--candidate` (grasp index), `--insert-mm` (the generator's) | the robot asset, the bowl | `data/results/robot/grasp_test/<tag>.json` |
| `frigidaire_arm_model.py` | Kit. Exports the arm collision model (hull vertices per link, link-frame offsets to the analytic FK at HOME_Q) for Kit-free checks. | none | the robot asset | `data/results/robot/arm_model.json` |
| `frigidaire_robot_conventions.py` | Kit. Convention and collider tests on the live asset: arm-collider press test, TCP and pad conventions, a loaded close. | `--run-id`, `--effort` (8), `--stiffness` (400) | the robot asset, a HOTEC v2 bowl | `data/artifacts/<run-id>/conventions.json` (+ `.jsonl`, frames) |
| `frigidaire_robot_conventions_fixture.py` | Kit-free. Trims a conventions record into the pytest fixture (values copied, never edited). | the record path (positional) | `data/artifacts/<run-id>/conventions.json` | `code/frigidaire/tests/fixtures/robot/conventions.json` |
| `frigidaire_robot_mount.py` | Kit-free. Which pedestal pose reaches a grasp at every dish's start and goal (analytic IK; arm collisions are not checked here). | `--instance` (required), `--grid` (`floor`, or `counter`), `--any-branch` (every IK branch) | the instance | `data/results/robot/mount/<instance>.json` |
| `frigidaire_robot_episode.py` | Kit. The arm executes an instance's moves (no teleport, no weld) under the harness: contact reports, auto-fail invariants, JSONL trial log, fixed-camera video. | `--instance` (required), `--profile` (`headline`, or `legacy_upright3`; in `code/frigidaire/src/dishsim_frigidaire/robot/flags.py`), `--test-case`, `--diagnostic-continue`, `--mount` (the profile's), `--max-moves`, `--max-wall-seconds` (1700), `--run-id`, `--trial-id` (`t00_nominal`) | the instance, the mount file, the Frigidaire build | `data/results/robot/runs/<run-id>/<instance>.json`, `data/artifacts/<run-id>/<trial-id>/` (trial log, video, frames) |
| `frigidaire_robot_report.py` | Kit-free. The Phase 0 report from the trial logs: plots per trial, a summary and `index.html` per run, every claim cited. | `--runs` (required), `--conventions`, `--report-run` (`p0_report`) | `data/results/robot/runs/`, `data/artifacts/` | `--out` (`REPORT.md` at the repo root), `data/artifacts/<run-id>/index.html` |
