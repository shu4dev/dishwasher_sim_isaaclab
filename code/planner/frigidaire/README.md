# planner/frigidaire

The HOTEC rearrangement benchmark on the Frigidaire twin, the MCTS planner's sweep and figure, the HOTEC loads and
top-5 loads, the results page and episode videos. Defaults are defined in the script itself unless another file
is named. Host = `python3` on the host (it schedules jobs in `dishsim-isaac`: at most 3 Kit jobs on GPU 1 plus 2
Kit-free jobs); Kit = through `code/util/run_kit.sh`; Kit-free = `code/util/run_py.sh`. Reference:
`code/frigidaire/docs/hotec_bench.md`, `code/frigidaire/docs/exposure.md`.

| Script | What it does | Key parameters (default) | Reads | Writes |
|---|---|---|---|---|
| `frigidaire_bench.py` | Kit-free library and CLI of the benchmark; the host modes are the orchestrator. Tiers: easy = 7 bowls, medium = 8 plates + 7 bowls, hard = 8 plates + 7 bowls + 8 cups; n dishes start on the counter slab, the rest in the racks. Goal track: reach the highest-exposure load; open track: build an own load, scored by S. | host modes `--generate`, `--plan-all`, `--run-all` (`--cameras` for stills), `--analyze-all`, `--videos`, `--full`, `--collect`; `--tiers` (all of `TIERS`, with the counter slack per tier), `--seeds` (0), `--max-attempts` (6), `--kit-jobs` (3), `--py-jobs` (2), `--algorithm` (open track: `baseline`, `mcts`; `TRACK_ALGORITHMS`); the learned placement rules are constants in the script (`FRONT_RIGHT_MAX_X_M`, `DROPPED_SLOTS`, `AT_GOAL`) | the Frigidaire build, the HOTEC assets | `data/results/benchmark/frigidaire_hotec/` (instances, plans, episodes, `compare/`), `data/media/benchmark/frigidaire_hotec/`, logs `data/logs/benchmark_frigidaire_hotec/` |
| `frigidaire_bench_kit.py` | Kit, one process per call (the bench launches it). `--start`: one generation attempt (counter pile and rack drops, joint settle, reproduction gate). `--sequence` / `--sequence-plan`: build a goal or an own load one dish at a time and certify the order. `--run`: every episode of one instance, each move teleported and settled, then the end check. | `--tier`, `--seed` (0), `--attempt` (0), `--pile-coverage` (0.5, `PILE_COVERAGE` in the script), `--max-wall-seconds` (7200), `--gate` (the load's joint gate, with `--sequence-plan`), `--usd` (`data/build/frigidaire_collection/usd/fdpc4221as.usdc`), `--baseline` (`data/results/benchmark/frigidaire_hotec/baseline/result.json`); settle limits `DEV_MAX_M` (0.08 m) and `BUILD_TICKS` in the script | an instance or attempt dir | `--out` (`data/results/benchmark/frigidaire_hotec`): `instances/attempts/<tier>_s<seed>_a<attempt>/start.json`, episode records; stills under `data/media/benchmark/frigidaire_hotec/stills/` with cameras |
| `frigidaire_mcts_sweep.py` | Kit-free. S versus planning budget of the track-B MCTS planner, on paper (nothing certified in Isaac). | `--instances` (required), `--budgets` (180 600 s) | instances | `data/results/benchmark/frigidaire_hotec/mcts_budget_sweep/`, one JSON per (instance, budget) |
| `frigidaire_mcts_figure.py` | Kit-free. Method figure of the MCTS planner: the search, what it found in 60 s, S versus budget. | none | `plans/open/<tier>/<id>__mcts.json`, `mcts_budget_sweep/*.json` | `data/media/benchmark/frigidaire_hotec/mcts_method.png` |
| `frigidaire_hotec_exposure_search.py` | Kit-free (Warp, CUDA when available). Highest-exposure full load of the 24 HOTEC pieces by coordinate ascent on the revision-5 score S; a sampled maximum, not a proof. | `--assets` (`data/assets/models/hotec_wheatstraw/v2`), `--start-layout` (`data/results/hotec/frigidaire/v8/layout.json`), `--sweeps` (3), `--top` (6), `--random` (2), `--seed` (0), `--samples` (500) and `--directions` (64) from `DEFAULTS` in `code/frigidaire/src/dishsim_frigidaire/exposure.py`, `--isolated-samples` (200), `--isolated-directions` (32), `--insertion-gate` | the assets, the start layout | `--out` (`data/results/exposure/frigidaire/hotec`): `search.json`, `best_layout.json` |
| `frigidaire_hotec_exposure_figure.py` | Kit-free. Method image of two loads: per-sample exposure top-down per rack, plus per-piece bars. | `--start`, `--best`, `--out` (all required), `--assets` (`data/assets/models/hotec_wheatstraw/v2`), `--samples` (500), `--directions` (64) | two layouts | the PNG at `--out` |
| `frigidaire_hotec_load.py` | Two stages. `--layout-only` (Kit-free): FCL rack layout of plates, bowls and cups, overflow to the counter. Kit: spawn, open the door, extend the racks, teleport, settle, stills and an orbit video. | layout: `--assets` (`data/assets/models/hotec_wheatstraw/v1`), `--bowls-upper` (4), `--plates` (`split`, or `front`), `--search`; Kit: `--layout` (required), `--sequential`, `--settle-timeout` (12 s), `--observation` (5 s), `--usd` (`data/build/frigidaire_collection/usd/fdpc4221as.usdc`) | assets, the layout | `--out-dir`: `layout.json`; `<tag>_evidence.json`, `<tag>_step_NN.png`, stills, video |
| `frigidaire_hotec_top5.py` | Top-5 exposure loads of all 24 dishes, each through the joint Isaac gate, then scored on the settled poses and rendered. `--all` (host) runs every stage, resumable. | `--level` (0; `LEVELS` in the script relaxes the capacity probe), `--parts` (`PARTS` = 2), `--kit-jobs` (3), `--py-jobs` (2); gate peak `GATE_PEAK_PEN_M` (0.005 m) and dish tolerance `DISH_TOL_M` (0.0008 m) in the script | the HOTEC v2 assets, the bench's families | `data/results/hotec/frigidaire/top5_20260929_touch08/`, `data/media/hotec_wheatstraw/top5_20260929_touch08/`, logs `data/logs/hotec_top5/touch08/` |
| `frigidaire_planner_video.py` | Kit. Stop-motion video of one episode: each executed move re-poses the dishes to their settled poses (no physics), with a caption. | `--instance`, `--episode`, `--out-dir` (all required), `--hold-frames` (18), `--fps` (24), `--renders-per-frame` (12), `--usd` (`data/build/frigidaire_collection/usd/fdpc4221as.usdc`) | the instance, the episode record and its `.analysis.json` | `<instance>_<algorithm>.mp4`, first and last frame PNGs, `*_video_evidence.json` |
| `frigidaire_bench_page.py` | Kit-free. The benchmark's results page as one folder to publish (sprites keep it under 255 files, 64 MB). | `--out` (records, default `data/results/benchmark/frigidaire_hotec`), `--media` (default `data/media/benchmark/frigidaire_hotec`) | records and media | `data/media/benchmark/frigidaire_hotec/page/`: `index.html`, `sheets/`, `analysis/`, `video/`, `files.json` |
