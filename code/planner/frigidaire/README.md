# planner/frigidaire

The HOTEC rearrangement benchmark on the Frigidaire twin, the MCTS planner's sweep and figure, the HOTEC loads and
top-5 loads, the results page and episode videos. Defaults are defined in the script itself unless another file
is named. Host = `python3` on the host (it schedules jobs in `dishsim-isaac`: at most 3 Kit jobs on GPU 1 plus 2
Kit-free jobs); Kit = through `code/util/run_kit.sh`; Kit-free = `code/util/run_py.sh`. Reference:
`code/frigidaire/docs/hotec_bench.md`, `code/frigidaire/docs/exposure.md`.

| Script | What it does | Key parameters (default) | Reads | Writes |
|---|---|---|---|---|
| `frigidaire_bench.py` | Kit-free library and CLI of the benchmark's run stage (code/src/bench/episodes.py): the sample -> instance conversion (`instance_of_sample`), track B's own-load plans (`--plan`, `--ban-plan`, `--resequence`), the episode world, the 4.5 bench's tables and host modes (history). Track A: greedy_offline, rrt_connect reach the sample's goal; track B: first_fit, mcts build their own load. The instance generator (`--goal`, `--finalize`, `--generate`, `--full`) retired 2026-11-01. | `--plan` (an instance), `--algorithm` (open track: `first_fit`, `mcts`; `TRACK_ALGORITHMS`), `--attempt` (0), `--out` (the results folder; its own-load bans count beside the old bench's), `--resequence` + `--instance`, `--final`; host modes `--plan-all`, `--run-all`, `--analyze-all`, `--videos`, `--collect` (the 4.5 bench); the learned placement rules are constants in the script (`FRONT_RIGHT_MAX_X_M`, `DROPPED_SLOTS`, `AT_GOAL`) | the Frigidaire build, the HOTEC assets, an instance | `<out>/plans/open/<tier>/`; history: `data/results/benchmark/frigidaire_hotec/` |
| `frigidaire_bench_kit.py` | Kit, one process per call (the bench stages launch it). `--start`: one start attempt of the initial stage (counter pile and rack drops, joint settle, reproduction gate, unstack rehearsal). `--sequence-plan`: build an own load one dish at a time and certify the order. `--run`: every episode of one sample (`--sample`) or old instance (`--instance`), each move teleported and settled, then the end check. `--stills`: the initial and goal stills of one sample only (the stills stage). | `--count`, `--n`, `--cap` (with `--start`), `--seed` (0), `--attempt` (0), `--pile-coverage` (0.5, `PILE_COVERAGE` in the script), `--max-wall-seconds` (7200), `--gate` (the load's joint gate, with `--sequence-plan`), `--algorithms`, `--media` (stills folder), `--usd` (`data/assets/frigidaire_fdpc4221as/usd/fdpc4221as.usdc`), `--baseline` (`data/results/benchmark/frigidaire_hotec/baseline/result.json`); settle limits `DEV_MAX_M` (0.08 m) and `BUILD_TICKS` in the script | a sample, an instance or a plan | `--out`: `instances/attempts/s<seed>_a<attempt>/start.json`, episode records; stills under `--media` with cameras |

| `frigidaire_mcts_figure.py` | Kit-free. Method figure of the MCTS planner: the search, what it found in 60 s, S versus budget. | none | `plans/open/<tier>/<id>__mcts.json`, `mcts_budget_sweep/*.json` | `data/media/benchmark/frigidaire_hotec/mcts_method.png` |
| `frigidaire_hotec_exposure_search.py` | Kit-free (Warp, CUDA when available). Highest-exposure full load of the 24 HOTEC pieces by coordinate ascent on the revision-5 score S; a sampled maximum, not a proof. | `--assets` (`data/assets/hotec_wheatstraw/usd`), `--start-layout` (`data/results/hotec/frigidaire/v8/layout.json`), `--sweeps` (3), `--top` (6), `--random` (2), `--seed` (0), `--samples` (500) and `--directions` (64) from `DEFAULTS` in `code/frigidaire/src/dishsim_frigidaire/exposure.py`, `--isolated-samples` (200), `--isolated-directions` (32), `--insertion-gate` | the assets, the start layout | `--out` (`data/results/exposure/frigidaire/hotec`): `search.json`, `best_layout.json` |
| `frigidaire_hotec_exposure_figure.py` | Kit-free. | `frigidaire_hotec_load.py` | Two stages. `--layout-only` (Kit-free): FCL rack layout of plates, bowls and cups, overflow to the counter. Kit: spawn, open the door, extend the racks, teleport, settle, stills and an orbit video. | layout: `--assets` (`data/assets/hotec_wheatstraw/usd`), `--bowls-upper` (4), `--plates` (`split`, or `front`), `--search`; Kit: `--layout` (required), `--sequential`, `--settle-timeout` (12 s), `--observation` (5 s), `--usd` (`data/assets/frigidaire_fdpc4221as/usd/fdpc4221as.usdc`) | assets, the layout | `--out-dir`: `layout.json`; `<tag>_evidence.json`, `<tag>_step_NN.png`, stills, video |

| `frigidaire_planner_video.py` | Kit. Stop-motion video of one recorded bench episode on the bench kit's scene (`make_backend`, dishes kinematic): the stored start, then each executed move's `poses_after` written, one tick, rendered, captioned (S_final and S_ref from the `.fair.json`); no physics.
