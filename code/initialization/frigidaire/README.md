# initialization/frigidaire

Build, stage, certify and package the Frigidaire FDPC4221AS twin, plus the claim test, the demo and the Isaac
start-state gate. Defaults are defined in the script itself unless another file is named. Three defaults come
from `code/frigidaire/src/dishsim_frigidaire/paths.py`: `ASSET_DIR` = `data/build/frigidaire_collection/usd`,
`COLLECTION_DIR` = `data/assets/models/frigidaire_fdpc4221as`, `IMAGE_DIR` = `COLLECTION_DIR/images`.
Kit = run through `code/util/run_kit.sh ... --headless`; Kit-free = `code/util/run_py.sh` (or host `python3`
where noted). Reference: `code/frigidaire/README.md`, `code/frigidaire/docs/geometry.md`.

| Script | What it does | Key parameters (default) | Reads | Writes |
|---|---|---|---|---|
| `stage_frigidaire_collection.py` | Host. Stages the reference material and the unchanged release history, regenerates the rack diagrams (runs the two rack previews and the clearance script of this folder) and the dimension image; never removes originals. | `--out-dir` (`data/build/frigidaire_collection`), `--reference-dir` (the installed or staged `references/`), `--archive-current VERSION` (copy the current usd/images/validation into `history/VERSION` instead) | references (`spec.pdf`, photos), archived bundles | `<out-dir>/{references,history,images,validation}/`, `validation/collection_manifest.json` |
| `build_frigidaire.py` | Kit-free. Builds the standalone appliance USD bundle without Isaac. | `--out-dir` (`ASSET_DIR`), `--component` (`UpperRack` or `LowerRack`: update one rack in an existing bundle); geometry `PARAMETERS` in `code/frigidaire/src/dishsim_frigidaire/geometry.py` | the source geometry | `fdpc4221as.usdc`, `parameters.json`, `geometry_validation.json`, `example_scene.usda`, fixtures, tableware, `README.md` |
| `frigidaire_collection_inspect.py` | Kit-free. Checks the current USD composition and that the bundle relocates. | `--collection-dir` (`COLLECTION_DIR`) | the collection's USD files | `<collection-dir>/validation/composition.json` |
| `frigidaire_asset_evidence.py` | Kit. Measures the appliance and removable basket and photographs the actual USD; run physics and renders as two jobs; `evidence.json` merges only reports whose scope, asset hashes and source hashes match. | `--usd` (`ASSET_DIR/fdpc4221as.usdc`), `--assembly-only`, `--physics-only` or `--render-only`, `--width` (1920), `--height` (1440) | the USD, the package sources (hashed) | `--out-dir` (`IMAGE_DIR/assembly`): `physics.json`, `renders.json`, `contacts.json`, `evidence.json`, gallery `index.html` |
| `package_frigidaire.py` | Kit-free. Checks every release gate and zips the collection; old load evidence never counts. Red until the evidence refresh. | `--collection-dir` (`COLLECTION_DIR`), `--check` (report only, write nothing), `--output` (a sibling `<collection>.zip`) | the collection and its reports | the ZIP |
| `frigidaire_upper_rack_preview.py` | Kit-free (NumPy, Matplotlib). Overhead, front and oblique views of the generated upper rack, with measurements. | `--out-dir` (`IMAGE_DIR/upper_rack`) | the source geometry | `upper_rack_{overhead,front,oblique}.png`, `upper_rack_overhead.svg`, `measurements.json` |
| `frigidaire_lower_rack_preview.py` | Kit-free. The lower-rack tines and the basket at its seat, plus three views of the basket alone; reuses the upper preview's helpers. | `--out-dir` (`IMAGE_DIR/lower_rack`) | the source geometry | `lower_rack_{overhead,oblique}.png`, `lower_rack_overhead.svg`, `basket_{front,top,oblique}.png`, `measurements.json` |
| `frigidaire_lower_rack_clearance.py` | Kit-free (no USD, FCL or Isaac). Measures the generated lower-rack and basket capsules. | `--out` (`data/build/frigidaire_collection/validation/lower_rack_clearance.json`) | the source geometry | the clearance JSON |
| `frigidaire_rack_dimensions_cm.py` | Kit-free. Dimensioned drawings of both racks in cm (teal = tape, orange = derived from tape, grey = photo-fit estimate). | `--out-dir` (`data/media/frigidaire_rack_dimensions`) | the source geometry | `frigidaire_{upper,lower}_rack_cm.png` (curated copies in `docs/figures/`) |
| `frigidaire_tape_check.py` | Kit-free. The user's tape numbers drawn exactly as written, from tape alone; conflicts red, guesses orange. | the `TAPE` table in the script, `--out-dir` (`data/media/frigidaire_rack_dimensions`) | `frigidaire_rack_dimensions_cm.py` (drawing helpers) | `tape_check_{upper,lower}_rack.png` |
| `frigidaire_cutlery_pose_search.py` | Kit-free. Head-down cutlery poses per basket compartment, FCL-checked against the closed appliance; a greedy pass picks one pose per slot. | `--out-dir` (`data/build/frigidaire_diagnostics`), `--write-candidates PATH` (freeze the per-kind choice lists) | the build at `ASSET_DIR`, `PARAMETERS["silverware_basket"]` | `cutlery_pose_search.json`, the candidates JSON |
| `load_frigidaire.py` | Kit-free. Plans a fixed-size mixed load with the authored contact geometry. | `--asset-dir` (`ASSET_DIR`), `--ban-file` (physics-rejected candidate keys), `--out` (`<asset-dir>/full_load_manifest.json`) | the build | the load manifest |
| `frigidaire_claim_layouts.py` | Kit-free. One FCL-checked rack-capacity claim layout, written as a full-load manifest. | `--variant` (required; `VARIANTS` = `A` in `code/frigidaire/src/dishsim_frigidaire/claims.py`), `--label` (the variant), `--ban-file`, `--asset-dir` (`ASSET_DIR`) | the build | `--out-dir` (`data/build/frigidaire_collection/validation/claims`): `claim_<label>_manifest.json`, `claim_<label>_geometry.json` |
| `frigidaire_full_load_evidence.py` | Kit. Validates and photographs a fixed mixed-load manifest: physics through a full rack and door cycle, renders replay the recorded states; `--settle-only` gives diagnostics, not a certification. | `--manifest`, `--usd` (both required), `--physics-only` or `--render-only`, `--settle-only`, `--width` (1920), `--height` (1440) | the manifest, the USD and the tableware beside it | `--out-dir` (`IMAGE_DIR/full_load`): `physics.json`, `pose_traces/`, renders |
| `frigidaire_claim_report.py` | Kit-free. Composes the claim test's report from the JSON verdicts. | `--claims-dir` (`data/build/frigidaire_collection/validation/claims`), `--media-dir` (`data/media/frigidaire_fdpc4221as/claims`) | `claim_<V>_geometry.json`, `<V>_settle/physics.json`, `<V>/physics.json` | `<claims-dir>/REPORT.md` |
| `configure_frigidaire_rendering.py` | Kit-free. Edits only the RTX metadata of the exported loaded scene and records the unchanged evidence inputs; repeat with `--require-render-pass` after rendering. | `--asset-dir` (`ASSET_DIR`), `--out-dir` (`IMAGE_DIR/full_load`), `--manifest`, `--require-render-pass`, `--render-log` | `full_load.usda`, `physics.json`, the manifest | `frigidaire_render_metadata.usda`, `render_settings.json` |
| `frigidaire_full_load_render.py` | Kit, render-only. Runs `frigidaire_full_load_evidence.py` unchanged with explicit RTX transparency settings and records the live settings. | `--out-dir` (`IMAGE_DIR/full_load`) | `physics.json` (the recorded states) | renders, `render_runtime.json` |
| `frigidaire_loaded_scene_smoke.py` | Kit. Opens the exported loaded USD directly (no spawn helper, no per-frame control) and checks its authored closed hold. | `--scene` (`ASSET_DIR/full_load.usda`), `--settled` (`full_load_settled.json` beside the scene), `--expected-count` (67) | the scene | `standalone_smoke.json` in `--out-dir` (`IMAGE_DIR/full_load`) |
| `frigidaire_demo.py` | Kit. Minimal loader: ordered opening and closing, or passive handle forces. | `--mode` (`scripted`, or `passive`), `--usd` (the current collection), `--x`, `--y` (0), `--yaw` (0, degrees) | the appliance USD | the `[RESULT]` line |
| `frigidaire_initial_state_validate.py` | Kit (defaults `--device cpu`, headless). One fresh Isaac process: a measured baseline (no `--manifest`) or the joint validation of a load manifest; the HOTEC bench and the top-5 search call it as their gate. | `--manifest`, `--out-dir` (required), `--order` (`upper_first`), `--max-wall-seconds` (240), `--peak-penetration-m` (`LIMITS` in `code/frigidaire/src/dishsim_frigidaire/random_poses.py`), `--usd` (`data/build/frigidaire_collection/usd/fdpc4221as.usdc`) | the manifest, the USD | `<out-dir>/result.json` |
| `polish_lower_rack.py` | Builds and previews (`--preview`, host NumPy) or installs (`--install`, container) the photo-informed standalone lower rack; replaces only the LowerRack subtree and backs up originals by content hash. | `--preview`, `--install`, `--out_dir` (`data/build/bosch800_lower_rack`), `--asset_dir` (`data/assets/models/bosch800`) | the appliance and loose-rack USDs in `--asset_dir` | previews in `--out_dir`, `installation.json` |
| `lower_rack_polish_evidence.py` | Kit. One PNG and one orbit MP4 of the revised lower rack after it settles on its wheels; no loading claim. | `--usd` (`data/assets/models/bosch800/lower_rack.usdc`), `--width` (1920), `--height` (1440) | the rack USD | `--out_dir` (`data/media/bosch800_lower_rack_polish`): PNG, MP4, `evidence.json` |
